# Dynamic Island for Windows (kompakt)

Angepasste Version des Windhawk-Mods
[Dynamic Island for Windows](https://windhawk.net/mods/dynamic-island-for-windows)
von Himanshu ([devcode90](https://github.com/devcode90)), Basis: Version 1.4.0.

## Änderung gegenüber dem Original

Die eingeklappte Musik-Pille zeigt nur noch **Uhrzeit | Album-Cover**.
Der Audio-Visualizer und die Platzhalter-Punkte daneben entfallen, die Pille ist dadurch schmaler.
Beim Drüberfahren öffnet sich weiterhin der volle Player inklusive Visualizer.

## Installation

1. [Windhawk](https://windhawk.net) installieren.
2. `dynamic-island-kompakt.wh.cpp` herunterladen.
3. In Windhawk **„Eine neue Mod erstellen“** klicken, den Editorinhalt durch den Inhalt der Datei ersetzen.
4. **„Mod kompilieren“** klicken und den Editor schließen.
5. Falls das Original „Dynamic Island for Windows“ installiert ist, dieses deaktivieren.

Die Einstellungen (Position, Theme, Wetter usw.) werden in Windhawk beim Mod unter *Einstellungen* gesetzt.
